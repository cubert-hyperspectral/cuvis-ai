# Configuration

Cuvis.AI uses Hydra for configuration management — composition, overrides, and config groups. This section is the reference for the Hydra layout and the schemas the trainers consume.

If you are looking for the directory layout of a typical `cuvis_ai/configs/` tree, see [Config Groups](https://docs.cuvis.ai/latest/reference/configuration/config-groups/index.md).
